# BenaExt - Aplicativo

Esta pasta contem a versao empacotada do BenaExt para Windows.

## Como usar

Execute:

```text
BenaExt.exe
```

Esta distribuicao e `onefile`: os recursos e bibliotecas necessarios ficam dentro de `BenaExt.exe`.

Se o Windows SmartScreen bloquear a abertura, clique em `Mais informacoes` e depois em `Executar assim mesmo`.

## Sobre o pacote

Esta versao foi gerada com PyInstaller em modo `onefile`, com tela de abertura e usando Qt/WebEngine para manter compatibilidade com a API do pywebview e com o fullscreen do aplicativo.
